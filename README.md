# Artur Baranouski

Independent developer. I build open-source tools that make AI agents accountable and test them in public, negative results included.

- **AgentLeash**: spending limits for AI agents as a Bitcoin Cash covenant, with an HTTP 402 paywall (chipnet). [agentleash-bch](https://github.com/ttimesai-star/agentleash-bch)
- **AgentLog**: a signed, hash-chained action log for agents, plus an MCP server. [agentlog](https://github.com/ttimesai-star/agentlog), [agentlog-mcp](https://github.com/ttimesai-star/agentlog-mcp)
- **Delivery Score**: checks paid x402 APIs before an agent pays them. [delivery-score](https://github.com/ttimesai-star/delivery-score)
- **Opener**: booking decisions from Qloo's taste graph, with the evidence attached. [opener](https://github.com/ttimesai-star/opener)
